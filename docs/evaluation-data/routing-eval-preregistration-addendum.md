# Pre-registration addendum
Written before round-2 results were seen; committed after round-2 results existed. Not applied as pre-registered.
1. Primary comparisons are read separately; a win at one N is not generalized to the other.
2. A difference under 5 points is reported as "no meaningful difference", even if its interval excludes 0.
3. Tier C-lite (N=10, registry and RAG): a point-estimate accuracy drop >10 points with model-written vs scripted briefs counts as a material weakness; the paired 95% interval is reported alongside.
4. Baseline merge counts are evidence that the problem exists; they are not part of router comparisons and are not evidence for the registry.
5. All results are on dev probes after label widening; no held-out set was run (D-007).
